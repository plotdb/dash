# design-2「報告」

給一個要把結論讀完的人。版心置中、整頁往下捲，沒有卡片、沒有陰影，
襯線字從標題一路套到座標軸。

看畫面：`http://localhost:64500/initiative/2nd/design-2/`
( 入口頁在 `/initiative/2nd/` )。

跟 `design-1` 比，def 的結構、crossfilter 的語意、用的圖表 block 全部相同。
以下只講不同的地方。


## 一個決定推出來的全部

**不填滿視窗，填滿版心。** 其餘每一條都是這句話的後果。

`def.layout.row` 從 `<[6.4em 1.15fr 1fr]>` 換成 `<[7.6em 19em 24em 15.5em]>` ——
全部是絕對值，沒有 `fr`。高度由內容決定，不是把剩下的空間分掉。頁面 CSS 跟著要蓋掉
`dash.css` 的 `.dash { height: 100% }`：

    .rp-board
      .dash
        height: auto
        overflow: visible

這兩處一改，同一個 `dash.board` 就從「一面儀表板」變成「一份文件」。
`gap` 也從 14px 放大到 26px —— 捲動的版面沒有「擠一擠多塞一格」的壓力。


## 沒有卡片

`block/panel/0.0.1/index.ls` 跟 design-1 的**逐字相同**，只有 `index.pug` 不一樣。
那份 pug 拿掉了背景、邊框、圓角與陰影，只留標題上方一條 1px 的線：

 - 圖表卡片與 KPI 用的是**同一條**線，所以四個數字跟底下五張圖看起來是同一份文件
 - 「篩選中」的狀態就是那條線變成 2px 加強調色。這一版沒有別的地方可以變 ——
   沒有邊框可以亮、沒有陰影可以深
 - 說明文字改成斜體、單獨一行，排版上就是圖說

印刷品沒有陰影，所以這裡也沒有。


## 字

`.rp-panel` 設了 `font-family: var(--rp-serif)`，**圖表裡的文字跟著變**：
svg 的 `text` 一樣吃 CSS 繼承，而 `@plotdb/chart` 沒有在自己的樣式裡寫死字體。
所以座標軸標籤、legend、direct label 全部是襯線，不必透過 config 傳。

( `cfg.font.family` 走的是 `@xlfont` 的字體物件，要的是 `{className}` 而不是
一個 CSS family 字串，不適合這種「整頁換字」的用法。 )


## 色票

規則跟 design-1 一樣 —— 色相留給資料，介面狀態只用深淺 —— 但「深淺」的方向相反：
深色底是往上提亮，紙上是往下壓暗。

低彩度、每個色相都壓暗，四色套印那種：靛 `#2f4b7c`、磚紅 `#b4553f`、
橄欖 `#7d8a4f`、赭黃 `#a9772b`。

兩個跟底色有關的設定剛好跟 design-1 相反：

    common: subset: {background: paper}   # 未選的往紙色退, 不是往白色退
    geo-ramp: <[#ece9e2 #2f4b7c]>         # 低端貼著紙色

地圖的低端在深色底上不能太暗（整座島會消失），在紙上則是反過來 ——
**沒有資料的縣市就該看起來像沒印到東西**。

格線也換成虛線（`dash: '2 3'`）：紙上的實線太搶，格線的工作是讓人對得到高度，
不是被看見。


## def 是附錄，不是抽屜

design-1 把 def 放在右側滑出的抽屜裡，因為那一版的畫面已經滿了。
這一版整頁可以捲，所以 def 就直接接在文件最後，一直在 —— 它本來就是這份文件的一部分。

功能完全相同（同一份 `dash.spec`、同一個編輯器、同樣可以套用重建），
少掉的只有抽屜的遮罩、滑入動畫與開關狀態。index.ls 因此少了 `open-def` / `close-def`
兩個 action 與 `defv` 這個 handler。


## light / dark

紙是這一版的預設。深色模式不是把紙反白 —— 那會變成一塊發光的板子 ——
而是**換一張深色的紙**：桌面更暗、紙比桌面亮一階，墨色降到不刺眼的米白。

四色套印那組壓暗的顏色在暗底上全部看不見，所以整組提亮一級。
同一份色票不可能兩個底色都成立，這是換模式真正要做的事 ——
不是換幾個變數，是重新回答一次「這個顏色在這個底上還讀得到嗎」。

上面那兩個跟底色有關的設定（`subset.background` 與地圖漸層低端）也跟著換：
規則沒變，仍然是「貼著紙色」，只是這張紙是深的。

機制六版共用，寫在 `../mode.ls`。


## 這一版沒做的

 - 窄螢幕只有版心內距縮小與標題縮字，12 欄的格線沒有重排
 - 沒有真的做列印樣式（`@media print`）。這一版長得像印出來的東西，
   但要印出來還得處理分頁與背景色
