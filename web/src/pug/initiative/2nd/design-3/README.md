# design-3「牆面」

給一個十公尺外走過去的人。磚與磚之間只有 3px 的縫，數字大到佔滿整格，
狀態用面積而不是小字。

看畫面：`http://localhost:64500/initiative/2nd/design-3/`
( 入口頁在 `/initiative/2nd/` )。

跟 `design-1` 比，def 的結構、crossfilter 的語意、用的圖表 block 全部相同。
以下只講不同的地方。


## 前提換了

這一版假設**沒有人坐在螢幕前面**。它掛在牆上，有人走過去看一眼。
所有決定都是從這一句推出來的，包括看起來只是美術問題的那些。


## 磚，不是卡片

一行 def 抵掉三行 CSS：

    gap: \3px

遠看的時候 1px 的邊框根本看不見，圓角也看不出來，陰影只會讓顏色變髒。
看得見的是**色塊的邊界**。所以 `block/panel/0.0.1/index.pug` 把背景換成實色、
拿掉邊框圓角陰影，分隔完全交給格子之間那 3px 的縫 ——
縫的顏色就是頁面底色，整面看起來是一張拼起來的板子，不是一堆浮在底色上的卡片。

頁首也是一塊磚，不是浮在上面的工具列，高度壓到 52px：
牆面上每一個像素的高度都該給圖。

panel 的 `index.ls` 一樣跟 design-1 **逐字相同**。


## 字與狀態

 - 標題一律大寫、緊排、800 —— 遠處要先讀到的是這一行
 - 說明文字排在標題**右邊**而不是下面，垂直空間留給圖；內容也砍到只剩一個詞
   （「依書系」「前六名」），牆上沒有人要讀操作說明
 - KPI 的數字用 `clamp(30px, 3.4vw, 58px)`，跟著格子縮 ——
   牆面螢幕的解析度不是固定的
 - 「篩選中」不只是一行小字，是整塊磚的上緣一道 4px 的強調色。
   遠看只看得到「哪幾塊亮起來了」

KPI 磚整塊上 accent 色、黑字，底下那一道 7px 的橫條就是「選中了全體的多少」。
design-1 的同一條是 2px —— 那一版是給近距離看的。


## 色票飽和一整級

遠距離看，低彩度的差別會糊在一起；design-2 那種紙上的墨色在十公尺外全部是灰的。
所以這一版走海報式的色票：`#ffd166` / `#26c6a6` / `#ff5d73` / `#8ab4ff`。

代價是四個色相各走各的，**沒有共同色族**。percent-list 是依占比深淺上色的
（顏色是位置的函數，不是項目的函數），沒辦法跟 line 逐項對齊，
所以它的漸層跟著打頭那個黃走，只要不跟地區的綠松撞成同一組就行。

地圖低端 `#36403d` 的理由跟 design-1 一樣：不能太接近磚底，
否則沒有資料的縣市會消失，剩下幾塊亮的浮在黑底上。


## 一格只有 3 欄寬的長條圖

版面是 4 個 KPI + 一張大的趨勢圖 + 跨兩列的地圖 + 底下三張並排，
所以長條圖只分到 3 欄。六個縣市的名字橫著排不下，這裡用：

    xaxis: {label: {direction: \auto}}

`auto` 先試水平，放不下改傾斜，再放不下轉垂直，都不行才抽稀。
以前的預設（`horizontal`）在這個寬度下只能隱藏其中幾個縣市。

地圖跟 design-1 一樣跨兩列：臺灣本島加離島的範圍又高又窄，
放在扁格子裡會縮成一小塊。


## 沒有 def 編輯器

牆上的螢幕不接鍵盤。這一版的 `index.ls` 因此少掉整段 spec / editor 的 runtime，
只留「清除篩選」跟一組唯讀的 chip —— chip 也不提供逐條刪除，
清掉就是全部清掉，走過去的人不會想記得哪一條是哪一條。

要看定義去 `design-1` 或 `design-2`。


## light / dark

深色是這一版的預設：牆上的螢幕通常掛在一個比它暗的空間裡。
淺色版是同一面牆在大白天的樣子 —— 磚提到接近白，縫反而變成比磚**深**的一條線。
縫永遠要比磚暗，不然拼貼會散掉，所以這一版的 `--wl-bg` 在兩個模式裡
一個比磚暗、一個也比磚暗，不是單純的對調。

海報色票也不能直接搬過去：螢光黃在白底上等於沒有，整組要換成壓暗一級的同色相。
「飽和」是相對於底色的，不是絕對值。

另外，色塊上的字要跟著底色換 —— `--wl-on-hot` / `--wl-on-acc`。
深色模式的 KPI 磚是亮色底配黑字，淺色模式是深色底配白字，
磚的顏色一換，字就得跟著翻面。

機制六版共用，寫在 `../mode.ls`。


## 這一版沒做的

 - 沒有輪播。真的掛在牆上通常要定時切換視角或自動捲動重點
 - 沒有「資料更新時間」與斷線狀態。值班畫面最需要的其實是這個
 - 沒有 responsive。它本來就是為固定比例的大螢幕排的
