# terminal「主控台」

給一個整天開著它的人。整頁等寬字 —— 包括圖表裡的文字 ——
而且整頁只有一個色相。

看畫面：`http://localhost:64500/initiative/variation/terminal/`
( 入口頁在 `/initiative/variation/` )。

跟 `desk` 比，def 的結構、crossfilter 的語意、用的圖表 block 全部相同。
以下只講不同的地方。


## 單色: 這一版唯一真正危險的決定

另外五個設計的規則都是「色相留給資料」。這一版把那條規則**拿掉了**：

    cat: colors: <[#ffd79a #ffb000 #c77f00 #7d5200]>

四個書系是同一個琥珀色的四階。分類靠的是明度順序與標籤，不是色相。

代價是真的：四條線交叉的地方分不出誰是誰。所以趨勢圖**一定**要配
`legend.mode: direct`（名字寫在線的末端），不能只給一疊色塊對照表 ——
在這個設計裡 direct 不是品味，是補救。

換到淺色模式時四階要整個反過來排：深色底上「最亮」等於「最強」，
紙上則是「最深」等於「最強」。


## 等寬字一路吃到座標軸

`.tm-panel` 設了 `font-family: var(--tm-mono)`，圖表裡的文字跟著變 ——
跟 report 把整頁換成襯線是同一招：svg 的 `text` 吃 CSS 繼承，
而 `@plotdb/chart` 沒有在自己的樣式裡寫死字體。


## KPI 的進度條是字元畫的

    ████░░░░░░░░ 29.5% of ALL

`block/kpi/0.0.1/index.ls` 跟 desk 的差別只有這一處，但那一處就是這個設計：
整個畫面上沒有別的東西是圖形，一條 CSS 畫的色條會變成唯一不是字的元素。

代價是解析度只剩 12 格，看不出 61% 與 64% 的差別 —— 這一版接受，
因為旁邊就寫著百分比。數字也沒有補間動畫：值班畫面重開的次數比誰都多，
每次都看它跑一遍是折磨。


## 語氣

 - panel 的標題一律大寫緊排，說明文字寫成參數的樣子：`sum(amount) by month × category`
 - 狀態不是藥丸，是一行字：`region=臺北市 ✕`
 - 頁首是狀態列不是標題列：`dash://variation/terminal  rows 144 / 864 · filters 1`
 - 按鈕是 `[ CLEAR ]`，方括號

趨勢圖用直線不用曲線（`line: {mode: \line}`）：月是離散的點，
曲線是在補一段不存在的資料。其他設計選了好看，這一版選了誠實。


## light / dark

深色是這一版的預設（終端機的預設）。淺色不是把終端機反白 ——
那會變成一塊發光的板子 —— 而是換一種紙本：報表紙。
琥珀色跟著壓成同色相的深琥珀，螢光色在紙上不存在。


## 這一版沒做的

 - 沒有鍵盤操作。一個長得像終端機的東西不能用鍵盤有點諷刺,
   但 crossfilter 的焦點管理是另一題
 - 沒有自動更新與「上次更新時間」。值班畫面最需要的其實是這個
 - 沒有 def 編輯器
